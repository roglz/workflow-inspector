# Workflow Inspector — Production Build E2E

## Purpose

Validate the compiled Workflow Inspector application
using Playwright and Chromium.

This is Stage 5, Step 5.2.

The tests run against Vite preview, which serves
the files generated by Vite build.

Vite preview is a local verification server,
not a public production hosting solution.

## Baseline

The verified Step 5.1 baseline is:

- 489 Vitest tests
- 28 Vitest test files
- 15 Playwright development E2E tests
- Successful TypeScript and Vite build
- Oxlint without errors or warnings
- Prettier without formatting issues

## Environment separation

Development E2E:

- Configuration: playwright.config.ts
- Server: Vite development server
- URL: http://127.0.0.1:5174
- Tests: 15

Production build E2E:

- Configuration: playwright.production.config.ts
- Server: Vite preview
- URL: http://127.0.0.1:4174
- Tests: 17

Both environments use Chromium.

## Production preparation

The production configuration starts its server
with the following command:

```bash
npm run build && npm exec -- vite preview --host 127.0.0.1 --port 4174 --strictPort
```

The build runs before preview starts.

If the build fails, the production E2E suite
does not run against an outdated build.

The preview server serves the generated dist
directory.

Playwright manages the server lifecycle.

Port 4174 must be available.

The configuration does not reuse an existing server.

## Test discovery

The production configuration includes:

- *.e2e.ts
- *.prod.ts

The original development configuration continues
to discover only *.e2e.ts.

Vitest does not discover the production-only file
because it does not have a .test.ts or .spec.ts
suffix.

## Production-only checks

The first production-only test verifies:

- index.html responds successfully
- No Vite development client path is present
- No source entrypoint path is present
- A compiled JavaScript asset is referenced
- A compiled CSS asset is referenced
- Both assets respond successfully
- Both assets contain data

The second production-only test verifies:

- The compiled React application loads
- The workflow input is visible
- An empty workflow can be audited
- The result contains zero nodes and findings
- JSON report export remains available

## Shared functional checks

The 15 existing E2E tests are reused unchanged.

They cover:

- Initial interface state
- Empty and malformed JSON
- Real R07 and R09 findings
- Severity and confidence filtering
- Local finding search
- Grouping by rule
- Local JSON import
- Invalid file rejection
- Report downloads
- Data minimization in exports
- Clearing previous results after editing

## Test artifacts

Production failure traces and screenshots use:

`node_modules/.cache/workflow-inspector-playwright-production`

Development and production artifacts remain separate.

Only synthetic test workflows should be used.

## Privacy

The tests run against local loopback addresses.

They use synthetic JSON and in-memory file uploads.

Report downloads are inspected through
Playwright's temporary download storage.

The tests do not require real workflow credentials.

No application network integration is added.

## Limitations

Vite preview does not reproduce the configuration
of an actual hosting provider.

This step does not test:

- Public deployment
- HTTPS certificates
- Hosting security headers
- Reverse proxy configuration
- Browser compatibility beyond Chromium
- Load testing
- Performance budgets
- Production monitoring

The source implementation is not modified.

These tests verify the local compiled artifact,
not a deployed public environment.
