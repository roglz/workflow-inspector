# Workflow Inspector — Cross-Browser Production E2E

## Purpose

Verify the compiled Workflow Inspector application
using Chromium, Firefox, and WebKit.

This is Stage 5, Step 5.4.

The tests run against the files generated by
TypeScript and Vite rather than the development server.

## Verified baseline

Before Step 5.4:

- 489 Vitest tests passing
- 28 Vitest test files
- 15 development E2E tests passing
- 17 production E2E tests passing
- 51 cross-browser development E2E tests passing

- Oxlint without warnings or errors
- Prettier checks passing

## Test server

The configuration uses:

`http://127.0.0.1:4175`

This port is reserved for this test suite.

The server is launched automatically by Playwright.

It is not reused if an existing process is already
listening on the configured port.

The server is stopped after the test run.

## Build process

The configured command is:

```bash
npm run build && npm exec -- vite preview --host 127.0.0.1 --port 4175 --strictPort
```

The build invokes the project's existing
TypeScript and Vite build process.

If compilation fails, the preview server
does not start.

This prevents testing an outdated build.

Vite preview is used for local validation.

It is not intended as a public hosting server.

## Reliability

The suite uses two Playwright workers.

Automatic retries are disabled.

If a test fails in any browser, the failure
must be investigated before closing Step 5.4.

A browser-specific failure must not be hidden
through test.skip or removed assertions.

## Privacy

The test workflows contain synthetic data.

No real credentials or private workflow
documents are required.

Local file uploads use in-memory buffers.

Report downloads are inspected through
Playwright's temporary download storage.

The application is accessed through localhost.

This step does not add network integrations
to the application.

## Limitations

Successful tests do not guarantee compatibility
with every browser release or operating system.

WebKit on Windows does not replace testing
Safari on macOS or iOS.

Vite preview does not reproduce the configuration
of an external production hosting provider.

The suite does not evaluate performance,
accessibility compliance, or deployment security.

These concerns require separate verification.
